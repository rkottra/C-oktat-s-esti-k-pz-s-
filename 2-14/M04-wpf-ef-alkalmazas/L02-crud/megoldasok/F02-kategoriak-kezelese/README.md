# Megoldás – 14-M04-L02-F02 · Kategóriák kezelése

WPF-projekt: `RaktarKategoriak.csproj` (`net8.0-windows`). Futtatás: XAMPP-ban indítsd el a MySQL-t, majd F5.

Ha a `root` felhasználónak van jelszava, írd be a `RaktarContext.cs` kapcsolati szövegébe.
