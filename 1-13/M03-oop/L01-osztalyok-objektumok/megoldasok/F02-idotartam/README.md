# Megoldás – 13-M03-L01-F02 · Időtartam-átváltó

- `Idotartam.cs`: egyetlen tárolt adat (`Masodpercek`, ellenőrzött), rá épülő számított tulajdonságok `get`-tel és `set`-tel (`Percek`, `Orak`), csak olvasható részek (`Ora`, `Perc`, `Mp`), két konstruktor `this(...)`-szal, `Hozzaad` metódus, `ToString()` `óó:pp:mm` alakban.
- `Program.cs`: átváltások, edzéslista, összegzés egy gyűjtő objektumba, maximumkeresés, átlag, bekérés kivételkezeléssel.

Futtatás: F5 (Visual Studio) vagy `dotnet run`. Próbáld ki 75 perccel vagy negatív órával is!
